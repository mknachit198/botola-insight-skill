# Provenance et composants tiers

Le moteur et les tests historiques proviennent du relais Raja Insight v8.2 fourni par l’utilisateur. Les fichiers embarqués du moteur sont conservés à l’identique ; `botola-insight/assets/engine_sha256.json` en donne les empreintes. Les adaptateurs et la documentation constituent le conditionnement Botola Insight Skill. La licence MIT a été choisie par le titulaire du projet dans cette session.

Les paquets Python ne sont pas redistribués dans le ZIP : ils sont installés depuis leurs distributions et conservent leurs propres licences. Les poids YOLOX sont téléchargés séparément depuis Megvii-BaseDetection/YOLOX ; le moteur d’origine indique leur licence Apache-2.0. Références : https://github.com/Megvii-BaseDetection/YOLOX et https://github.com/Megvii-BaseDetection/YOLOX/blob/main/LICENSE.

Les vidéos, images de match, annotations et données de référence ne sont pas redistribuées. La licence MIT du code ne confère aucun droit sur ces contenus ni sur les marques des clubs. Aucun logo de club n’est fourni.

Les autres modules historiques (interface web, Sportmonks, statistiques expérimentales) sont conservés pour préserver le moteur et ses tests ; le parcours de la compétence ne les active pas implicitement. Aucune clé ni configuration d’accès à un service n’est fournie.
